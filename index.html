功能

从当下的读数，到一周的趋势。

三个位置，各司其职：菜单栏看现在，Widget 看一小时，Details 回看更长的时间。

01 · 菜单栏

抬眼一看，就知道当下。

点开菜单栏，即可查看当前系统功耗和最近 60 秒的曲线。供电来自适配器还是电池、电量流向、电池健康与温度，都在同一个面板里。

  • 系统功耗与 60 秒实时曲线
  • 输入 → 系统 → 电池 的供电流向
  • 电池健康（估算）、温度与循环次数
  • 适配器能力与电池功率

02 · 桌面 Widget

放在桌面，变化就有了轮廓。

中号 Widget 展示已记录的一小时均值与趋势。比起追逐瞬间的起伏，把一段时间放在一起看，更容易发现耗电变化。

  • 一小时均值与趋势柱状图
  • 标明快照更新时间
  • 不需要打开 App 也能看到

Widget 展示快照，不是持续刷新的实时仪表；请结合更新时间阅读。

03 · Details 历史

把时间拉开，看见规律。

在 Details 窗口切换 60 秒、1 小时、1 天、7 天四档范围，回看实际采集到的功耗记录，并查看记录均值、峰值和更详细的电池数据。

  • 60 秒 / 1 小时 / 1 天 / 7 天
  • 记录均值与峰值
  • 电池电压、电流与满充容量
  • 未采集的时段保留空缺，不补写成 0

读懂功率

同样是「瓦」，说的不是同一件事。

很多人把充电器瓦数、充电功率和 Mac 耗电混为一谈。Voltyn 把它们分开显示，并标清各自含义。

01系统功耗System power
Mac 当前的整体用电。菜单栏显示即时读数，Widget 显示一小时均值，两者时间尺度不同。
02输入功率Input power
当前从供电输入侧读到的功率。系统没有提供可用读数时，Voltyn 不会拿适配器能力或 0 来代替。
03适配器能力Adapter capability
充电器报告的最大供电能力，例如 100 W。它不等于 Mac 此刻的耗电，也不代表正以这个功率充电。

Voltyn 支持哪些 Mac？

支持搭载 Apple Silicon（M 系列芯片）的 MacBook，需要 macOS 14 或更新版本。Intel Mac 与台式 Mac 不在支持范围内。

Voltyn 多少钱？需要订阅吗？

在中国大陆 Mac App Store 售价 ¥8，一次购买即可使用，没有订阅，也没有 App 内购买。其他地区价格以 App Store 显示为准。

为什么充电器写着 100 W，读数却小很多？

适配器能力是充电器最多能提供的功率，系统功耗是 Mac 当前实际用电，输入功率是当前供电输入侧的读数。三者含义不同，读数较低并不代表充电器或线材有问题。

为什么 Widget 和菜单栏的数字不一样？

菜单栏显示即时系统功耗；中号 Widget 显示已记录的一小时均值，并受快照更新时间影响。时间尺度不同，数字不同通常是正常的。

Voltyn 会上传我的数据吗？

不会自动上传。Voltyn 采集的功耗历史保存在本机，没有自动遥测。只有你主动发送邮件、截图或反馈时，相应内容才会离开设备。
