适用范围

本页说明 Voltyn 的本地功耗记录、拟提供的诊断导出，以及上架前网站预览的数据处理边界。App 尚未上架，最终发布版本仍待验收。

诊断预览与导出仍在开发。本页对该功能的说明是计划行为，不代表它已发布可用。公开支持邮箱也仍待确认。

本地功耗数据

Voltyn 使用系统可提供的电源相关信息来展示读数，并在本机保存 App 自己采集的功耗历史。菜单栏、Widget 与 Details 根据各自用途展示即时读数、快照或历史。

这些 App 自有历史不会通过自动遥测上传。历史记录取决于实际采集，不包含从未采集到的时段。

具体历史保留与清理路径，将随最终验收版本确认。本页不承诺尚未确认的保存时长、后台连续采集或自动清理行为。

主动反馈与诊断

诊断功能尚在开发，本网站不接收上传。

目前没有诊断上传后端或文件提交表单。

计划中的诊断报告可能包含选定的功耗数据、时间戳、App 与系统版本，以及手动填写的备注。功能提供后，应先预览，再由你决定是否导出或通过支持渠道分享。

导出到本地文件与发送给他人是不同操作。只要你主动发送邮件、截图或报告，相应内容就可能离开设备。因此我们不会把主动反馈描述为「所有数据永不离开设备」。

请在分享前移除不必要的信息。不要发送 Apple 账户密码、支付资料、设备序列号或完整系统日志。GitHub Issues 是公开渠道，内容、你的 GitHub 身份与后续讨论可能被他人查看或索引。普通问题只应提交最小必要的非敏感文字，禁止附上诊断日志、序列号或账号信息。

当前没有已实施的服务端诊断存储或删除时限。本页不承诺尚未建立的保留、删除或回复时限；如需私密诊断材料，必须先安排并确认私密渠道；公开 Issues 不能替代私密接收。

本网站与 GitHub Pages

本网站使用 GitHub Pages 托管。网站自身不加入分析追踪、广告像素或第三方字体，没有注册、支付、诊断上传表单，也不使用非必要 Cookie 或浏览器本地存储追踪访问者。

页面文字、样式、图标与脚本由网站自身提供。功耗数值与曲线是标注过的虚构示意，不会读取你电脑上的真实电源数据。

正常访问会向 GitHub Pages 发起网络请求。GitHub 说明，为安全目的会记录访问者 IP 地址。网站没有分析脚本，并不意味着托管方没有访问日志。具体处理规则请参阅 GitHub Pages 数据收集说明与 GitHub 隐私声明。

外部链接与服务

支持页链接到 Apple 官方退款指引。点击外部链接后，将适用该服务自己的规则；本网站不代为登录、不处理支付，也不决定退款结果。

真实 App Store 地址及支持邮箱确认后，网站可提供相应跳转。打开邮件链接只是交给你的邮件客户端，不会由本站自动发送邮件或附加文件。

你的选择

  • 可以只阅读网站与排障说明，不提交任何问题描述。
  • 主动反馈前删去不必要的内容，选择是否附上截图或后续可用的诊断报告。
  • 本地导出的报告由你保管；分享前应再次检查内容。
  • 若对已发送内容有疑问，可以先通过公开问题入口询问处理方式，但不要再次公开敏感内容；本页不承诺尚未建立的删除时限。

联系与后续更新

支持邮箱和诊断功能定稿后，本说明需要与实际版本一并核对。影响数据处理方式的变化会更新到本页，并标注更新日期。

有普通使用问题？公开提问。

通过网站仓库的 GitHub Issues 反馈非敏感问题。问题内容和你的 GitHub 账号身份会公开，提交需要登录 GitHub。

前往 GitHub 公开提问

不要附上诊断日志、设备序列号、账号信息、密码、支付资料或其他私人内容。本站没有私密上传入口。若问题需要私密材料，须先安排并确认私密渠道，再决定是否分享。

公开支持邮箱尚未提供。我们不承诺固定回复时间，也不保证退款获批。
